## 2026-09-30: full-match team shape analysis + staff report

**Why this direction.** Of the things clubs actually do with tracking
data, four were picked to build toward:
1. Opposition shape report (weekly, before a match)
2. Post-match shape review (weekly, after a match)
3. Pressing / counter-pressing
4. Off-ball runs and space creation (feeds the separate recruitment project)

Physical output (distance, sprints) was deliberately skipped: clubs get
it from GPS vests, and speeds from broadcast video are noisy.

Two tracks:
- **Track A (now):** analysis on open full-match tracking data, which is
  what a club analyst does with provider data.
- **Track B (later):** making the video pipeline handle full matches
  (stream frames instead of loading all of them, 5 fps, cut detection,
  automatic pitch calibration). The current pipeline handles ~30 s
  clips; a full match would take ~39 h CPU and ~840 GB RAM as written.

**Built this session (Track A, step 1):**
- `scripts/download_metrica.py`: fetches Metrica sample games 1 and 2
- `soccervision/metrica.py`: loader into a source-agnostic format
  (players table + frames table, meters), possession derived from events
- `soccervision/shape.py`: back line, front line, centroid, length,
  width, area per frame and team; phases of play; 15-min summaries;
  average positions
- `soccervision/report.py` + `report_template.html`: self-contained HTML
  match report for staff (findings, block timeline, pitch maps, table)
- `analyze_shape.py --game N --open`: runs everything, opens the report
- `tests/`: 7 unit tests (`python -m pytest tests`)
- `docs/shape-analysis.md`: how it's built and why, the sanity checks,
  how to rebuild it on other data

**Bugs caught by sanity checks (worth remembering):**
- Keeper detection used average x over the match; keepers switch ends at
  half-time, so their average is ~halfway. Fixed: average distance from
  halfway.
- A goal was logged as `BALL OUT / WOODWORK-GOAL`, not a SHOT. Fixed:
  goals credited by who kicks off next.

**Results:** game 1 Home 3-1 Away, game 2 Home 3-2 Away. Both teams
in both games sit within normal ranges (28-35 m from back line to front
line and ~36-39 m wide without the ball; 44-50 m wide with it). Metrica
data is anonymized, so the real team names are unknown and can't be
recovered.

**Decisions:**
- No published web pages (claude.ai artifacts). Every output is a file
  generated by a script in this repo, so it can be rerun without help.
  (One page was published before this rule:
  https://claude.ai/artifact/JbqBgDS6L8wZZeH7qd1fDK. It's still up,
  and can be deleted on request.)
- The metric code never reads a provider's raw format; new sources get
  a loader into the players/frames tables.

**Open question raised:** does a bigger gap between lines go with
conceding more? Not answerable from 2 games / 7 goals. Method agreed:
precise hypothesis → frequent outcome (shots, box entries) → compare
shape before those moments with all other out-of-possession time →
check score, cause-vs-effect and fatigue → 10+ matches. Note: the
report measures back-to-front length; the defence-to-midfield gap isn't
measured yet.
